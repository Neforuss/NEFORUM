- iPhone and iPad: if a sideloading app such as Feather shows 192.0.0.2 or "not connected to the internet" on mobile data, install over Wi-Fi. Settings > Updates on iPhone and iPad now says so next to a new version, and [docs/install-iphone.md](../install-iphone.md) explains why (Feather's Semi Local install uses the phone's mobile data address, which is 192.0.0.2 on IPv6-only carriers such as T-Mobile US) and the Feather setting that may help when Wi-Fi is not available.
